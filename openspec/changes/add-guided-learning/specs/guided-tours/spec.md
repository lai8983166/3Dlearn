## ADDED Requirements

### Requirement: 演示场景的入口

PBR 模块侧边栏顶部、光学模块侧边栏顶部 MUST 各有一个"演示场景 Demos"下拉按钮，展开后列出该模块的 3-4 个预设场景。点击任一场景 MUST 立即开始执行；执行期间下拉 MUST 折叠但显示当前场景名 + 进度。

#### Scenario: 进入演示场景
- **WHEN** 用户点击"演示场景"下拉并选择"看 Fresnel"
- **THEN** 下拉折叠，画布顶部出现旁白条"将相机移到掠射角，关闭 Specular/Normal，留下 Diffuse + Env 观察 Fresnel 反射"
- **AND** 球体的相机视角在 1.5 秒内动画过渡到掠射角
- **AND** Specular 和 Normal 层自动关闭，Diffuse 和 Env 层自动开启
- **AND** 旁白条右侧有"跳过"按钮，点击立即停止场景并保留当前状态

#### Scenario: 场景结束后恢复
- **WHEN** 演示场景所有步骤执行完毕
- **THEN** 旁白条显示"演示完成"并在 1.5 秒后淡出
- **AND** 所有参数保持演示后的状态（用户可继续探索）
- **AND** 不自动还原到演示前的参数

### Requirement: 场景脚本结构

每个演示场景 MUST 由一个有序步骤数组定义，每个步骤 MUST 包含：目标参数（store 字段名 + 值）、过渡时长（毫秒）、旁白文本。步骤之间 MUST 串行执行，下一步在前一步过渡完成后开始。

#### Scenario: 步骤串行执行
- **WHEN** 一个场景定义了 3 个步骤，时长分别为 1500ms / 1000ms / 2000ms
- **THEN** 整个场景总执行时长为 4500ms（±100ms 容差）
- **AND** 每个步骤开始时旁白文本更新为新步骤的内容

### Requirement: 跳过与中断

任何演示场景 MUST 可被用户操作中断。用户点击"跳过"按钮、按 Esc 键、或在场景执行期间手动操作任何 store-controlling UI 元素（滑杆、开关）MUST 立即停止场景执行。

#### Scenario: 用户手动操作中断场景
- **WHEN** 场景正在执行第 2 步（动画过渡相机视角），用户拖动 Diffuse Intensity 滑杆
- **THEN** 场景立即停止，剩余步骤不再执行
- **AND** 旁白条消失，用户操作的值生效
- **AND** store 中没有遗留的"场景执行中"标志

### Requirement: PBR 模块演示场景预设

PBR 模块 MUST 提供至少 4 个预设演示场景：分层贡献揭示、Fresnel 掠射、GGX vs Blinn-Phong 对比、金属 vs 非金属。每个场景 MUST 用具体的参数变化展示一个核心概念。

#### Scenario: 分层贡献揭示
- **WHEN** 用户运行"分层贡献"演示场景
- **THEN** 场景先关闭所有 4 层（球体全黑），然后依次以 1.5 秒间隔打开 Diffuse、Specular、Normal、Env，每打开一层旁白说明该层贡献
- **AND** 公式 HUD 在每层打开时同步显示对应公式

#### Scenario: Fresnel 掠射演示
- **WHEN** 用户运行"看 Fresnel"演示场景
- **THEN** 场景调整相机到球体边缘正对相机的掠射视角
- **AND** Diffuse + Env 留开，Specular 和 Normal 关闭
- **AND** 旁白解释"垂直入射（中心）反射弱，掠射角（边缘）反射强——这就是 Fresnel"

### Requirement: 光学模块演示场景预设

光学模块 MUST 提供至少 3 个预设演示场景：薄透镜方程验证（u=2f → v=2f, m=-1）、实像→虚像切换动画、凹透镜发散。每个场景 MUST 通过参数变化让用户看清核心物理现象。

#### Scenario: 实像→虚像切换动画
- **WHEN** 用户运行"实像→虚像"演示场景
- **THEN** 场景在 6 秒内动画化物体从 u=3f 移动到 u=0.5f
- **AND** 物体经过焦点时（|u - f| < 0.1）旁白条高亮"注意：像距趋向无穷，即将切换到虚像"
- **AND** HUD 的像距 v 与像类型在动画过程中实时更新

#### Scenario: 薄透镜方程验证
- **WHEN** 用户运行"薄透镜方程"演示场景
- **THEN** 场景设置双凸透镜 f=2，物体 u=-4（即 2f 处）
- **AND** HUD 高亮 v=+4（=2f）和 m=-1.0（倒立等大）
- **AND** 旁白条显示"u=2f → v=2f, m=-1：物像等大、倒立实像"
